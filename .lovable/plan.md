# Hotel Wonder Hill Inn website

## Build
- Create a shared premium hotel header, mobile menu, booking actions, footer, and reusable editorial sections.
- Build nine distinct pages: Home, Rooms, About, Amenities, Dining, Gallery, Experiences, Location, and Contact.
- Use the ten supplied hotel photographs throughout; preserve them as direct static imports and never add stock or placeholder imagery.
- Add a fullscreen gallery lightbox, responsive navigation, restrained scroll/hover motion, click-to-call links, email links, directions, and enquiry actions.

## Visual direction
- Forest green, charcoal, warm beige, and restrained brass.
- Cinematic full-width photography, asymmetrical editorial layouts, generous whitespace, and a refined serif/sans-serif pairing.
- Mobile-first layouts with stable image crops, readable overlays, and no excessive card treatment.

## Content and trust
- Use only the supplied address, phone numbers, email, rating, room categories, pricing language, amenities, and attraction distances.
- Avoid fake testimonials, unsupported superlatives, invented room details, and an unverified WhatsApp link; room booking will use direct phone/contact actions instead.

## Search and sharing
- Add unique titles, descriptions, Open Graph text, canonical paths, and Twitter card metadata to every page.
- Add Hotel and LocalBusiness structured data, descriptive image alt text, internal links, robots rules, and sitemap entries for all public pages.

## Validation
- Check the current build status, then verify desktop and mobile pages, navigation, lightbox, map, calls, and contact links in the live preview.
